# Recursos para el análisis funcional

En esta sección se recogen diferentes herramientas bioinformáticas que podrían utilizarse para estudiar las variantes genéticas y los genes relacionados con el cáncer digestivo.

## 1. SNPnexus

https://www.snp-nexus.org/

Herramienta que permite anotar variantes genéticas y explorar sus posibles consecuencias funcionales.

## 2. GTEx

https://gtexportal.org/

Base de datos que proporciona información sobre la expresión génica en diferentes tejidos humanos y las asociaciones eQTL.

## 3. GeneCards

https://www.genecards.org/

Recurso que ofrece información sobre genes humanos, sus funciones y sus características biológicas.

## 4. Open Targets

https://platform.opentargets.org/

Plataforma que permite explorar asociaciones entre genes, dianas terapéuticas y enfermedades.

## 5. PubMed

https://pubmed.ncbi.nlm.nih.gov/

Base de datos bibliográfica que permite localizar publicaciones científicas para apoyar la interpretación biológica.

**Nota:** Estos recursos se proponen como herramientas de apoyo para posibles análisis posteriores. Su inclusión no significa que se hayan utilizado para generar nuevos resultados en este proyecto.
